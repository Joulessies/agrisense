1. Abstract & System Overview

In precision agriculture, monitoring and forecasting vegetative vitality in specialized succulents such as Aloe barbadensis Miller presents unique challenges. Due to Crassulacean Acid Metabolism (CAM), aloe vera operates on diurnal stomatal cycles inverted relative to common C3 and C4 crops. Standard static regression models fail to account for cumulative temporal dependencies, delayed dehydration responses, and microclimatic phase shifts.

This paper presents the AgriSense Bi-LSTM Neural Engine, a stacked 2-layer Bidirectional Long Short-Term Memory recurrent neural network trained on continuous hourly IoT telemetry (ambient temperature, relative humidity, soil moisture, and solar illuminance). By incorporating both forward and backward temporal sequences over a 24-hour sliding lookback window, the model achieves high predictive fidelity with an $R^2$ of 88.75% on Plant Vitality Index forecasting and 95.82% on 24-hour Soil Moisture trajectory predictions, enabling early detection of root asphyxiation and drought stress up to 18 hours before visible foliage degradation.

Key Innovation: The integration of Bidirectional LSTM layers enables the system to capture the full 24-hour CAM diurnal stomatal cycle—correlating daytime thermal stress with nocturnal stomatal carbon assimilation and nocturnal transpiration recovery.

2.2 Sliding Window & Data Normalization

Continuous telemetry was transformed into sliding sequences using a 24-hour lookback window ($T = 24$). Each sequence $X_i = [x_{i}, x_{i+1}, \dots, x_{i+23}]$ maps to dual target variables $Y_i = [y_{\text{vitality}}, y_{\text{moisture}}]$ at timestep $i+24$. To avoid lookahead bias and target leakage, Min-Max Normalization was applied where min-max parameters were computed solely on the training partition: 

x_scaled = (x - x_min_train) / (x_max_train - x_min_train)

The dataset was partitioned into an 80% training set (1,152 hourly sequences) and a 20% out-of-sample holdout test set (288 hourly sequences).

3. Neural Network Architecture & Hyperparameters

The architecture comprises stacked Bidirectional LSTM layers designed to capture multi-scale temporal dynamics, followed by dense projection heads and dropout regularization.

Input Sequence: (Batch Size, Sequence Length = 24, Features = 4) │ ▼ Layer 1: Bidirectional LSTM (64 Hidden Units × 2 = 128 Output Dim) • return_sequences = True | Recurrent Dropout = 0.20 │ ▼ Layer 2: Bidirectional LSTM (32 Hidden Units × 2 = 64 Output Dim) • return_sequences = False (Extracts final latent state) | Dropout = 0.20 │ ▼ Dense Hidden Projection (32 Units, Activation = ReLU) • Batch Normalization + Dropout (rate = 0.20) │ ▼ Output Layer: Linear Projection (2 Units) • [Plant Vitality Index (0–100%), Projected Soil Moisture (%)]

3.1 Mathematical Formulation of Bi-LSTM

For each sequence timestep $t$, the forward LSTM processes history from $t=1 \to T$, computing hidden state $\overrightarrow{h_t}$, while the backward LSTM processes from $t=T \to 1$, computing $\overleftarrow{h_t}$. The concatenated output vectors represent complete diurnal context: 

h_t = [ \overrightarrow{h_t} ; \overleftarrow{h_t} ] \in \mathbb{R}^{2 \cdot d_h}

3.3 Training Configuration

  • Loss Objective: Smooth L1 / Huber Loss ($\delta = 1.0$) to prevent gradient explosions during intermittent telemetry sensor spikes.
  • Optimizer: Adam ($\alpha = 0.001, \beta_1 = 0.9, \beta_2 = 0.999, \epsilon = 10^{-8}$).
  • Batch Size: 32 sequences per training iteration.
  • Epochs: 60 epochs with Early Stopping (patience = 8 monitored on validation loss).

4. Botanical Significance (CAM Diurnal Mechanics)

Unlike conventional crops, Aloe vera demonstrates **Crassulacean Acid Metabolism (CAM)**. Stomata remain tightly closed throughout the sunlit hours (10:00–16:00) to minimize transpirational water loss in arid environments. At night, stomata open to fix atmospheric $CO_2$ into malic acid stored in large central vacuoles.

Model Adaptation: Conventional 1-step regression models misinterpret elevated daytime solar irradiance and high temperatures as immediate dehydration damage. The 24-step Bi-LSTM accounts for the nocturnal recovery window, distinguishing between healthy daytime stomatal closure and physiological heat necrosis.

6. PyTorch Implementation Reference

The core neural network module as instantiated in ml/lstm_crop_predictor.py:

import torch
import torch.nn as nn

class BiLSTMCropPredictor(nn.Module):
    """Stacked Bidirectional LSTM with Dropout and Fully Connected Heads."""
    def __init__(self, input_dim=4, hidden_dim=64, num_layers=2, output_dim=2, dropout=0.2):
        super(BiLSTMCropPredictor, self).__init__()
        self.lstm = nn.LSTM(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            bidirectional=True,
            dropout=dropout if num_layers > 1 else 0.0
        )
        self.fc1 = nn.Linear(hidden_dim * 2, 32)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(dropout)
        self.fc2 = nn.Linear(32, output_dim)

    def forward(self, x):
        # Input tensor: (batch_size, seq_len=24, input_dim=4)
        lstm_out, _ = self.lstm(x)
        last_timestep = lstm_out[:, -1, :] # Final state from sequence
        out = self.fc1(last_timestep)
        out = self.relu(out)
        out = self.dropout(out)
        return self.fc2(out) # [Vitality Index %, Soil Moisture %]
